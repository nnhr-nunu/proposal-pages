1. ご提案

1.1 要点

  1. 予約の台帳はアプリに置きます。 予約の入口はこれまでどおりサロンボードです。各スタッフが LiME で持っている先の予約も、6か月先までアプリに入れられます。
  2. 歩合の精算まで自動で計算します。 現金の分は「スタッフからお店へ渡す額」、キャッシュレスの分は「お店からスタッフへ払う額（手数料を引いた後）」を、スタッフごと・月ごとの精算書にします。いまの請求書の元にできます（インボイスの登録番号や消費税の額を載せる形にも、この金額の中で合わせます）。
  3. あとから消せない記録にします。 予約は消せず、会計の直しも履歴に残ります。締めた月はオーナーしか直せません。

1.3 アプリでできるようになること

予約
スマホでは1日の予約を縦に並べて、iPad・パソコンではスタッフ別の1日の表と週の表で見られます。6か月先まで入れられ、同じスタッフの時間の重なりや、3席を超える予約は、入れるときにお知らせします。LiME から移すときは、日付と担当を引き継いだまま続けて入れられます。
会計と会計チェック
予約からそのまま会計へ進めます。技術と店販を分けて入れ、支払い方法（現金・クレジットカード・ホットペッパーのポイント・楽天ペイ・au PAY・交通系IC・iD/QUICPay）を選びます。2つの方法の併用もできます。会計まだの予約は一覧に残り、予約の金額と違うときは、理由（料金の調整・割引・メニュー変更・店販の追加など）を1タップで残せます。店販だけのお客様は、予約なしで会計できます。
歩合と月末の精算書
スタッフごとに、技術・店販・キャッシュレス手数料の率を設定します。月末に、現金の分（お店へ渡す額）とキャッシュレスの分（お店から払う額）、その差し引きを精算書にします。率を変えても、過去の精算は変わりません。オーナーが月を締めると確定し、印刷と書き出しができます。締めた月のあとで返金したときは、返金した月の精算で差し引きます。
売上
スタッフは自分の売上だけ、オーナーは全員分を見られます。表計算ソフトで開けるファイルに書き出せます。
サロンボードからの取り込み
サロンボードの予約のファイルを取り込み、アプリの予約と照らし合わせます。サロンボードに未入力の予約、時間や担当が違う予約、時間の重なりを一覧で出します。サロンボードでキャンセルや日時の変更があった予約は、アプリにも反映します（迷うものは一覧に出します）。同じファイルで、キャッシュレスの会計の金額がアプリと合っているかも確かめます。
シフトと営業時間
スタッフごとの出勤の型を決め、日ごとに変えられます。開店・閉店時間や臨時休業も、月のカレンダーで変えられます。休みのスタッフに予約を入れようとしたときや、営業時間の外に入れようとしたときは、お知らせします。
ログインと見られる範囲
スタッフごとに自分のログインを持ちます。お店の iPad は何人かで使うので、画面の上で「操作する人」を4桁の番号で切り替えます。スタッフは、ほかのスタッフの金額・売上・精算書を見られません。お客様の一覧の書き出しは、オーナーだけができます。画面のロックは、iPhone の画面ロック（顔認証・パスコード）とアプリのログインの2重です。iPhone をなくしたときは、オーナーの画面からその人のログインを止められます。
記録
キャンセルは、理由（お客様のご都合・当日・ご連絡なしなど）を残さないとできません。キャンセル料をいただいたときは、会計で金額を入れられます。会計を確定したあとの直しは「取り消して入れ直す」形で、前の内容が残ります。日が過ぎても会計のない予約は、会計まだとしてオーナーの画面に出続けます。誰が・いつ・何をしたかを、オーナーが見られます。
カルテ・メニュー・店販の商品
お客様ごとのメモと来店履歴（いつ・何を・担当・いくら）を残せます。メニューはサロンボードと同じ形（スタッフ料金とオーナー料金を分けたまま）で、料金の変更日を決めて登録できます。店販の商品と値段も登録できます。

1.4 アプリでできないこと

サロンボードとの自動連携
サロンボードには、外部のアプリとつなぐ公式の仕組みがありません。無理に自動化すると、サロンボードの画面が少し変わるだけで止まります。予約と売上は、ファイルで取り込みます。
ネット予約との重なりを防ぐこと
現金のお客様は「予定」のままで、来月以降の予約は月初までサロンボードに入らないため、同じ時間にネット予約が入るのを、サロンボードの側では防げません。アプリは、取り込んだときに時間の重なりとして出します。取り込みは毎日、またはネット予約が入った日がおすすめです。
会計の入力の一本化
税理士さんへお渡ししている売上はサロンボードから出しているため、キャッシュレスのお客様の会計は、これまでどおりサロンボードにも入れていただきます（アプリとの2か所です）。2つの金額が違うものは、予約のファイルを取り込んだときに一覧で出します。
シフトと営業時間の一本化
ネット予約に関わる分は、これまでどおりサロンボードでも設定をお願いします（アプリとの2か所で設定します）。
アプリに入れなかった来店の発見
見つけられるのは、サロンボードに予約があって、アプリで会計がないもの（キャッシュレスのお客様の会計漏れ）までです。現金のお客様の予約もアプリに入れることを、お店の決まりにしていただくのが前提です。
今回は作らないもの
ネット予約の受付ページ、LINE 連携、カード決済そのもの、在庫管理、給与計算、会計ソフト向けの書き出し、お客様向けの領収書・レシートの発行、予約のお知らせ（メール）、回数券・前払いの残高の管理。

1.6 品質と保証

  1. 納品は、一緒に確かめてからにします。 決めた機能の一覧に沿って動くことを確かめていただいてから納品とします。
  2. 不具合は、納品後6か月は無償で直します。 「決めたとおりに動かない」ものが不具合です。ご連絡をいただいたら、原則2〜3日以内に状況をお知らせし、営業が止まるような不具合は優先して直します。
  3. 入力の間違いは、お店側で直せる作りにします。 予約・会計・メニューなどの入力の直しは、アプリの画面からできます（直した履歴は残ります）。困ったときは、納品後6か月の間は、控えのデータから戻す作業もお手伝いします。
  4. 大きな仕様の変更や機能の追加は、別にご相談します。 納品後6か月の間は、サロンボードのファイルの形やアプリを動かす場所のサービスが変わったときも、小さな直しで済むものは保証の中で直します。大きな作り直しになるときと、納品後7か月目以降の直しは、ご相談のうえ、その都度お見積もりします。
  5. プログラムとデータをお渡しします。 ほかの開発者にも引き継げる形でお渡しします。

4. 補足

4.1 サロンボードで気になった点とアプリでの対応

  1. 現金のお客様を入れる「予定」は予約として数えられていません。 名前と時間だけでメニューや金額とつながらないので、予約の一覧にも売上にも来店履歴にも出てきません。アプリでは現金のお客様も予約として入れるので、売上と来店履歴に残ります。
  2. 「予定」で席を使っていても空きの表示は減りません。 受付できる数は全体で3つ（セット面3席と同じ）なので、予定で1席使っている間にネット予約が3件入ると4件が重なることがあります。アプリでは担当の時間の重なりと3席を超える時間を「重なり一覧」に出します。ネット予約の受付を止めるのはサロンボード側でしかできないので、アプリでは取り込んだ時点で気づける形になります。
  3. 電話予約は金額が入っていないものが多くありました。 金額が空欄だと予約と売上を突き合わせられません。アプリではメニューを選ぶと金額が入り、会計のときに実際の金額と違えば分かるようにします。
  4. 集計の画面によって合計が違うことがあります。 ある月は画面によって数千円の差がありました（割引の扱いが画面で違うためと思われます）。アプリでは基準にする数字を1つに決めて、どの画面でも同じ合計になるようにします。
  5. 同じ予約がサロンボードとアプリの両方に入ることがあります。 取り込むときは日付・時刻・担当・お名前で照らし合わせて二重にしません。アプリにすでにある予約には「サロンボードにも入っている」印を付けるだけで、アプリにない予約（ネット予約など）だけが新しく入ります。迷うものは候補から人が選びます。サロンボードでのキャンセルや日時の変更もアプリに反映します。
  6. サロンボードのお客様情報には書き出しのボタンが見当たりませんでした。 そのため3段階で移します。まずサロンボードの予約のファイルから台帳を自動で作ります（同じ方か迷うものは一覧に出すので、お店で選んでください）。次に LiME から表計算ソフトで開けるファイルが出せれば、お名前・ふりがな・電話番号を取り込みます（ほかの形のときは別にご相談します）。足りない分は手で入れます（お名前とふりがなだけでも始められます）。

4.2 長く使うための仕組み

4.2.1 メニューの変更・値上げのとき

  • 料金を変えても、過去の売上・来店履歴・精算書の金額は変わりません。予約を入れた時点の料金が、その予約の記録として残ります。
  • 「いつから新しい料金か」を決めて登録できます。値上げの日より前の予約は約束した金額のまま、それ以降の予約に新しい料金が付きます。歩合の率も同じです。

4.2.2 データの保管

  • データはインターネット上の保管場所に保存され、自動で控えが取られます。iPhone をなくしてもデータは残り、その iPhone からは、ログインを止めれば見られなくなります。
  • オーナーはいつでも全データをファイルで書き出し、手元に控えを残せます。
  • お客様の名前や電話番号を扱うので、ログインした人しか見られない作りにします。書き出したファイルにもお客様の情報が入るので、保存する場所（お店のパソコンなど）を決めておくことをおすすめします。
  • スタッフが辞めたときは、その人のログインだけを止められます。記録は残ります。

4.2.3 お店側でできること

  • メニューの追加・料金の変更・値上げの日の設定
  • スタッフの追加と停止、歩合の率の変更、支払い方法の追加
  • シフトと日ごとの営業時間の変更
  • データの書き出し（控え用）

操作の説明書には、よくある困りごとと直し方も載せます。

4.3 Web アプリについて

今回は、iPhone のホーム画面にアイコンを置いて開く Web アプリの形です。普通のアプリと同じように開けます。App Store の審査が要らないため、安く・早く作れて、直したいときもすぐ反映されます。同じアプリが、お店の iPad とパソコンでもそのまま使え、画面の幅に合わせてスタッフ別の表に変わります。

4.3.1 アプリの入れ方（予定）

導入のときに、画面つきの手順書をお渡しします。1台5分ほどで、各自で入れられます。分からないところは、メッセージや画面の写真でお聞きください。

  1. お送りするアプリのアドレスを、iPhone・iPad の Safari で開きます。
  2. 画面下の共有ボタン（四角から上向きの矢印）を押し、「ホーム画面に追加」を選びます。
  3. ホーム画面にアイコンが出るので、次からはそこから開きます。
  4. 最初の1回だけ、スタッフごとのログインをします。

パソコンでは、Chrome または Edge でアドレスを開き、ブックマークするか、アドレス欄の「インストール」から入れられます。
