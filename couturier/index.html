ご要望書と、いまお使いのサロンボードの実際の画面を確認してまとめました。専門用語はできるだけ使っていません。このページの下の方には、実際の画面のイメージ（モック）も付いています。タブを押して切り替えられますので、触りながらご覧ください。

1. 結論

  1. 作るのは、サロンボードの代わりではありません。 予約の受付は今までどおりサロンボードで受けていただき、このアプリは「お店の中の台帳」として使います。
  2. 必要な機能は、最初から全部入れます。 予約・会計・売上の合計・カルテ・サロンボードからのデータ取り込みまで、毎日の営業に要るものを一式で作ります。料金も、それ全部で1つの金額です（§9）。
  3. 月々の保守費用はいただきません。 ふだんの変更はお店側でできる作りにして、操作の説明書もお渡しします。大きな改修のときだけ、都度お見積もりで呼んでください。
  4. いちばん大事な機能は2つです。「会計がまだの予約がその日のうちに分かること」と「予約の金額と実際の売上が合っているか分かること」です。

2. いま困っていること（サロンボードを見て分かったこと）

  1. 現金のお客様を入れる「予定」は、予約として数えられていません。「予定」は名前と時間だけで、お客様情報・メニュー・金額とつながっていないため、予約の一覧にも、売上にも、来店履歴にも出てきません。記録に残らないのは、画面の仕組みがそうなっているためです。
  2. 席が埋まっていても、空きの表示は減りません。 受付できる数は全体で3つ（セット面3席と同じ数）ですが、「予定」で席を使っている時間でも表示上の空きは減りません。予定で1席使っているときに新しい予約が3件入ると、実際には4件が同時に進む形になりえます。
  3. 電話予約は、金額が入っていないものが多い状態でした。 金額が空欄だと、あとから「予約の金額と売上が合っているか」を比べられません。
  4. 集計の画面によって、合計が少し違うことがあります。 実際に、ある月の集計では画面によって数千円の差がありました（割引の扱い方が画面で違うためと思われます）。ミスがなくても数字はズレるので、「どの数字を正とするか」を1つに決めて比べられる仕組みが要ります。

3. このアプリで変わること

こといまアプリを使うと
月末の申告合わせスタッフ各自が自分の現金売上を集計して申告スタッフごとの合計が自動で出るので、確認するだけになります
会計の入れ忘れその日のうちに気づく方法がない閉店前に「会計がまだの予約」の一覧を見るだけ（1〜2分）で気づけます
予約の重なり空き表示が当てにならず、起きてから分かる入力した時点で「時間が重なっています」「3席を超えます」と知らせます
お客様の前回の内容サロンボードの画面を行き来して確認カルテを開けば、前回のメニュー・金額・担当がそのまま出ます

時間の目安として、月末の集計・申告の作業は、スタッフ4名で月に合計2〜4時間ほどと見ています（1人あたり30分〜1時間という仮定です）。アプリを使えば、この作業は「数字を確認する15分ほど」に置き換わります。

金額の話も正直に書きます。もし月に平均1万円ほどの会計が2件、記録から漏れていたとしたら、1年で約24万円が台帳に残らない計算になります。これは「もし漏れていたら」の試算で、実測ではありません。ただ、お店は月に100件以上の会計がある規模ですので、漏れが起きる余地自体は十分にある大きさです。また、予約の重なりで1件をお断りする事態になると、お客様1人あたりの平均金額（約1万5,000円）に加えて、お詫びと日程調整の手間がかかります。このアプリは重なりを「防ぐ」ものではなく「入れる前に気づける」ようにするものです。入れるかどうかは、最後は人が選べます。

そして何より、記録が残るので、誰かを疑う必要がなくなります。 申告漏れや計算違いは、人がやる以上ゼロにはなりません。大事なのは、起きたときに記録で確認できることです。

4. できること

  • 予約：スタッフごとに今日・明日の予約が見られます。現金のお客様も含め、全員を正式な予約として入れられます。変更・キャンセルもできます
  • 会計：予約からそのまま会計へ。金額と支払い方法（現金／クレジットカード／QR・電子マネー／ポイントなど）を選ぶだけ。店販の追加や割引も入れられます
  • 会計チェック：会計がまだの予約は一覧に残ります。予約の金額と売上が違うと、その場で分かります。「割引」「メニュー変更」「店販追加」などの理由を1タップで残せるので、理由のある差は正常として扱い、理由のない差だけが月末に一覧で出ます
  • 売上：自分の今日・今月の売上、お店全体、スタッフごとの合計が自動で出ます。表計算ソフトで開けるファイル（CSV）での書き出しもできます
  • カルテ（簡易版）：お客様ごとのメモと、来店履歴（いつ・何のメニューで・担当は誰・いくらか）が自動で並びます。薬剤の配合記録や写真のような本格機能は入れていません
  • メニュー・商品の管理：メニュー名・料金・所要時間、店販商品の登録・変更が、お店側でできます（値上げのときの仕組みは §7）
  • サロンボードからの取り込み：サロンボードの売上明細とお客様情報を、ファイル（CSV）で取り込めます（詳しくは §5）

入れていないもの：ネット予約の受付ページ、LINE連携、カード決済そのもの、在庫管理、給与計算（ご要望書どおりです）。

5. サロンボードとの連携について（正直なご説明）

  1. 完全な自動連携は、きちんとした形では作れません。 サロンボードには、外部のアプリと自動でつなぐための公式な仕組みが用意されておらず、画面上にも連携のメニューはありませんでした。無理に自動化する方法もありますが、サロンボードの画面が少し変わるだけで止まる不安定なもので、おすすめしません。
  2. 代わりに、ファイル（CSV）での受け渡しができます。 サロンボードの売上明細とお客様情報には、書き出しのボタンがあることを確認しました。これを取り込めば、売上合わせとお客様情報の移行は手入力なしでできます。取り込むときは、同じデータが二重に入らないようチェックし、「新しく入った件数・飛ばした件数」をその場で表示します。
  3. 予約の一覧については、書き出しボタンが見当たりませんでした。 公式の案内には「予約データの出力」という機能名があるので、別の画面にある可能性があります。場所と中身が確認できれば、予約も取り込めるようにします（確認のお願いは §13）。

7. 長く安心して使うための仕組み

メニューの変更・値上げのとき

  1. 料金を変えても、過去の数字は変わりません。 予約を入れた時点の料金が、その予約の記録として残る作りです。来月に値上げしても、先月までの売上や来店履歴の金額はそのままで、集計が後からズレることはありません。
  2. 「いつから新しい料金か」を指定できます。 値上げ日より前に受けた予約は約束した金額のまま、これからの予約には新しい料金が付きます。
  3. サロンボード側とのズレをお知らせします。 サロンボードのメニューとアプリのメニューで、名前や金額が違うものがあれば一覧で出ます。「片方だけ直して、もう片方が古いまま」という事故を防ぎます。なお、サロンボード側の変更まではこのアプリからは行えません。そこは今までどおりサロンボードで変更していただき、ズレに気づけることがこの仕組みの役割です。

データの保管

  1. データはインターネット上の保管場所に保存され、自動で控えが取られます。iPhoneをなくしてもデータは残ります。
  2. それとは別に、お店側でいつでも全データをファイルで書き出せます。万が一、開発者と連絡が取れなくなっても、お店のデータがお店の手元に残る形です。
  3. アプリを動かすための契約（保管場所など）は、お店の名義で作ります。費用の支払い先もお店から直接になるので、開発者を経由しません。

安心のための仕組み

  1. スタッフごとに自分のログインを持ちます。「誰が入力したか」が分かり、スタッフが辞めたときはその人のログインだけを止められます。
  2. 間違えて消しても取り消せるよう、予約のキャンセルやメニューの変更は「消す」のではなく「無効として残す」方式にします。

8. お店側で完結できること（月々の保守費用なし）

このアプリは、月々の保守費用をいただかずに使えることを前提に作ります。そのために、次のことを最初から入れます。

  • メニューの追加・料金変更・値上げ日の設定は、管理画面からお店側でできます
  • スタッフの追加・停止、支払い方法の追加も、管理画面からできます
  • データの書き出し（バックアップ用）は、いつでもお店側でできます
  • 操作の説明書（画面つき）をお渡しします。よくある困りごとと、その直し方も載せます
  • 作ったプログラム一式（ソースコード）もお渡しします。将来、別の方に直してもらうこともできます

納品後の6か月間は、不具合を無償で対応します。 使い始めてから出る問題は、作った側の責任として対応します（詳しくは §10）。その後は、大きな改修（新しい機能を足す、画面を大きく変える等）のときに、都度お見積もりで呼んでいただければ大丈夫です。小さな文言変更やメニュー変更は、上記のとおりお店側で完結できます。

10. 品質と保証について

個人開発で金額を抑えている分、「きちんと動くのか」が心配になるのは自然なことだと思います。保証の範囲を、先に書いておきます。

  1. 納品のときは、一緒に確認してからにします。 決めた機能の一覧に沿って、実際に動くかどうかを確認していただいてから、納品とします。
  2. 不具合は、納品後6か月は無償で直します。 「決めた通りに動かない」ものが不具合です。ご連絡をいただいたら、原則2〜3日以内に状況をご連絡し、お店の営業が止まってしまうような不具合は優先して対応します。
  3. 不具合ではないものは、分けます。 「使い方を変えたい」「新しい機能を足したい」は改修になるので、その都度お見積もりします。入力ミスなど、お店側の操作で変わってしまったデータの修正は保証の対象外です（控えのデータから戻す作業はお手伝いします）。
  4. 外の都合で変わるもの。 サロンボードのファイル形式が変わったり、iPhoneやブラウザの大きな仕様変更があったりして調整が必要になった場合は、その都度ご相談とさせてください。軽い調整で済むことも多いです。
  5. プログラムとデータをお渡しすること自体も、保証の一つと考えています。 万が一、開発者と連絡が取れなくなっても、お店のデータとプログラムがお店の手元に残り、別の方に引き継げる形にします。

ご質問への回答です。今回は、iPhoneのホーム画面にアイコンを置いて開く Web アプリ形式です。普通のアプリと同じように開けますが、App Store の審査が要らないため、安く・早く作れて、直したいときもすぐに反映されます。カメラのような特別な機能を使うわけではないので、この形式で十分です。将来どうしてもストアのアプリにしたくなった場合も、データの仕組みはそのまま使えます。
