# proposal-pages

提案資料など「先方に見せるページ」だけを置く、公開リポジトリです。GitHub Pages でそのまま URL 化して渡すための置き場です。

## フォルダ構成

- 1案件 = 1フォルダ。フォルダ名は店名・人名を避けた短い英字にします（例：`couturier/`）
- 各フォルダの `index.html` が、その案件の公開ページです
  - URL：`https://nnhr-nunu.github.io/proposal-pages/<フォルダ名>/`
- ルートの `index.html` は入口の案内だけです。案件へのリンク一覧は置きません

## 公開ルール（漏らさないために）

1. **入れてよいのは「先方に見せる前提で作った資料」だけ。** 調査メモ・金額戦略・交渉メモ・Claude向け指示書などの内部資料は、絶対にこのリポジトリに入れません（内部資料は案件ごとの非公開リポジトリへ）。
2. **先方の経営数字は実数を出しません。** 売上・客数・客単価・スタッフ別売上などは、概数やサンプル値に置き換えてから公開します。「先方に直接渡す版」と「公開版」は分けて作るのが原則です。
3. **個人が特定される情報は、もともと公開されている範囲まで。** 店舗スタッフ名・メニュー料金など公開情報は可。お客様の名前は実名を入れず、サンプルのみ。
4. **全ページに `<meta name="robots" content="noindex, nofollow">` を入れます。** 検索エンジンに載せないためです。
5. **Git の履歴には残ることを前提にします。** 後からファイルを消しても履歴から辿れるので、「消せば大丈夫」ではなく「そもそも実数を入れない」が原則です。
6. **案件が終わったらフォルダを削除します。** 残し続ける理由がある場合は、その旨をこの README に書いてから残します。

## Pages の設定（リポジトリ作成後に1回だけ）

GitHub の Settings → Pages で：

- Source：Deploy from a branch
- Branch：`main` / `(root)`
- Save

数分で `https://nnhr-nunu.github.io/proposal-pages/` が有効になります。
